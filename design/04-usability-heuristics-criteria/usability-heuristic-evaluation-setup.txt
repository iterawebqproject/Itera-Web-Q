2. Evaluation Criteria

The system executes automated static code analysis to audit web frontend code against a 19-point heuristic checklist derived from Nielsen's 10 Usability Heuristics.

Heuristic Mapping & Inspection Principles
* H01: Visibility of system status (5 rules) - Inspects for required fields cues, redirection delays, hyperlink styling, unique page titles/headers, and active navigation indicators.
* H02: Match between the system and the real world (1 rule) - Inspects the `lang` attribute on the root element.
* H03: User control and freedom (2 rules) - Inspects media controls and clear exit/close buttons on modals.
* H04: Consistency and standards (2 rules) - Inspects for maximum font-family usage and consistent structural tags (<nav>, <aside>, <footer>) across pages.
* H05: Error prevention (2 rules) - Inspects helper text for credentials and proper semantic HTML5 input types.
* H06: Recognition rather than recall (1 rule) - Inspects the placement of search fields in conventional locations.
* H07: Flexibility and efficiency of use (1 rule) - Inspects responsive design via viewport meta tags and media queries.
* H08: Aesthetic and minimalist design (2 rules) - Inspects reduced-motion fallbacks for animations and limits maximum color palettes.
* H09: Help users recognize, diagnose, and recover from errors (2 rules) - Inspects the avoidance of reset buttons and the presence of error notification systems.
* H10: Help and documentation (1 rule) - Inspects icon-only buttons for accessible labels or tooltips.

Issue Classifications & Severity
* Essential: Critical usability issues that completely block core tasks or trap users in unintended states (e.g., instant redirects, missing media controls, lack of error notifications).
* Pragmatic: Task-oriented and functional usability issues that hinder user operations, efficiency, or layout navigation (e.g., missing responsive design, generic page titles, improper semantic inputs).
* Hedonic: Experiential, psychological, or aesthetic design elements that affect user comfort, emotion, and inclusion (e.g., missing prefers-reduced-motion queries, inconsistent fonts, excessive color usage).

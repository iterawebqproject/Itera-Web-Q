PA11Y EVALUATION SETUP & CRITERIA

1. Configuration Setup

Pa11y Options
* Version: 9.1.1
* standard: WCAG2AA (Default)
* includeWarnings: true
* includeNotices: false
* timeoutMs: 60,000 ms (Minimum: 10s)
* waitMs: 1,000 ms (Maximum: 10s)
* retries: 1

Browser & Viewport Config (Desktop Simulation)
* Dimensions: 1350px width x 940px height
* Device Context: isMobile: false, hasTouch: false
* Chrome Flags: Headless mode, --no-sandbox, --disable-dev-shm-usage

2. Evaluation Criteria

The system uses the HTML CodeSniffer (htmlcs) test runner to evaluate the HTML DOM against WCAG 2.1 standards.

Compliance Levels (WCAG2AA)
* Level A: Fundamental accessibility rules (e.g., missing alt text, keyboard navigation support).
* Level AA: Intermediate accessibility rules (e.g., minimum text color contrast ratio of 4.5:1).

Issue Classifications
* Error: Definitive WCAG violations.
* Warning: Potential violations that require manual verification.
* (Notices are strictly excluded to focus on actionable violations).

3. Experimental Environment & Methodology

All automated evaluations were executed completely in a controlled local environment to eliminate network latency variations from serverless platforms.  

Hardware & OS Specifications
* Machine: Apple Mac running on an Apple M3 chip
* Memory: 8 GB Unified Memory
* Operating System: macOS Sequoia 15.7.3  

Software & Browser Specifications  
* Browser Engine: Google Chrome (version 147.0)
* Execution Mode: Automated Headless mode (--no-sandbox)
* Evaluation Period: April 7 - 11, 2026

Testing Methodology  
* Execution Flow: Automated sequential loop across all targeted web pages.  
* Test Frequency: 1 execution run per page to ensure a single-pass assessment baseline.
